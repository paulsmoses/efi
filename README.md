# Ephraim Foundation — Website Redesign

Self-contained static site. To host on GitHub Pages:

1. Push this `site/` folder's contents to your repo (or push the whole repo and set Pages source to `/site`).
2. In repo Settings → Pages, set source to the branch/folder containing `index.html`.
3. Site will be live at `https://<username>.github.io/<repo>/`.

No build step — `index.html` is fully self-contained (styles, scripts, fonts inlined).
